# Datasets and credits

Queryopsy never downloads data at runtime and never needs a Kaggle account or API token, for players, for CI or for publishing.
The pipeline runs once on a maintainer's machine; only the processed SQLite files in `data/db/` are committed (under 5 MB in total).

## Current status

Until the real files are placed in `data/raw/`, every case is built from **synthetic placeholder data** generated by `pipeline/` (files in `data/samples/*_placeholder.csv`).
The app shows a "Placeholder data" label on such cases. Placeholder data contains no real people or companies.

**Before committing processed data from a file you supplied, confirm the licence of that exact copy** and update the table above.
ODbL data requires attribution and that the derived database stays under ODbL; keep this file and the in-app source line when you redistribute.

## What the pipeline changes

* Parses and normalises values (dates, Indian digit grouping, `N/A`, broken UTF-8), keeps raw spellings where a puzzle depends on them (for example city names).
* Takes a deterministic sample when a file is larger than the case needs.
* Adds fictional helper data where a case needs it (rider payouts, bank accounts, payroll months). Names are generated from neutral syllables.
* Plants a small number of documented anomalies: see [PLANTED.md](PLANTED.md). Nothing else is invented.
