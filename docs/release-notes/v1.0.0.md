## Queryopsy v1.0.0

The first release of the zero-server SQL forensics simulator.

**Play:** https://himanshu-5680.github.io/queryopsy/ (works offline after the first visit)

### Downloads
- `Queryopsy-v1.0.0.apk`: Android 7.0+, no permissions required. Enable "Install unknown apps" for your browser or file manager to sideload it.
- `queryopsy-web-v1.0.0.zip`: the full offline website. Unzip and run `python -m http.server` inside the folder (see HOW-TO-RUN.txt).

### Highlights
- 6 investigations, 24 levels: funding, quick commerce, catalogue integrity, UPI fraud and payroll.
- Python 3.13 + SQLite running on your device via Pyodide; no account, no trackers, no network.
- Diff feedback, friendly errors, autocomplete, clickable ER diagram, hints, history, certificates (PNG/PDF).

See the [changelog](https://github.com/Himanshu-5680/queryopsy/blob/main/CHANGELOG.md) for details.
