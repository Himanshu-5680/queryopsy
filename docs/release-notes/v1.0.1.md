## Queryopsy v1.0.1 - Case File edition

Layout fixes plus a full redesign: every investigation now looks and feels like a real detective case file.

**Play:** https://himanshu-5680.github.io/queryopsy/ (works offline after the first visit)

### Downloads
- `Queryopsy-v1.0.1.apk`: Android 7.0+, no permissions required (versionCode 2, upgrades v1.0.0 in place and keeps your progress). Enable "Install unknown apps" for your browser or file manager to sideload it.
- `queryopsy-web-v1.0.1.zip`: the full offline website. Unzip and run `python -m http.server` inside the folder (see HOW-TO-RUN.txt).

### Fixed
- The results table no longer overlaps the Evidence Room, the Evidence Room tabs are never covered by the schema list, and the editor hint bar no longer gets cut off.
- Checked at 1024x450 up to 1920x1080, phones, tablets and 110-150 % zoom in both themes: no overlaps, no sideways scrolling.
- Below 1180 px wide the Evidence Room becomes a drawer (Evidence button or Alt+E). Android Back closes things one step at a time.
- Wrap-aware line numbers, better contrast, larger touch targets, proper screen-reader tabs and announcements.

### New look
- **Dossier** (light): manila folders, typewriter type, rubber stamps, evidence tags, paper clips and redaction bars.
- **Crime Lab** (dark): cork evidence board, pinned notes, red string between ER diagram tables and a soft flashlight vignette.
- Findings are Exhibits A, B, C...; solving one stamps SOLVED, the last one CASE CLOSED (no animation with reduced motion).
- The certificate is now an Official Forensic Audit Report.

See the [changelog](https://github.com/Himanshu-5680/queryopsy/blob/main/CHANGELOG.md) for the full list of fixes.
